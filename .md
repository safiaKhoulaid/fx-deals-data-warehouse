## 🎯 Features

### Core Functionality

✅ **Multi-Channel Ingestion** - Import deals via secure JSON API or Bulk CSV Upload.
✅ **Idempotency Engine** - Advanced duplicate detection to prevent processing the same deal twice.
✅ **Strict Validation** - Custom annotations for ISO Currency codes and logical validation.
✅ **ACID Transactions** - Reliable data persistence using PostgreSQL.
✅ **Error Management** - Centralized exception handling implementing RFC 7807 (ProblemDetail).

### Technical Excellence

🔐 **Security** - Input sanitization and validation layers.
📊 **Observability** - Structured logging and detailed failure reporting.
🔄 **MapStruct** - High-performance, type-safe object mapping.
📝 **Clean Code** - SOLID principles with a separated DTO pattern.
🧪 **100% Test Coverage** - Full Unit and Integration testing suite.
🐳 **Docker Ready** - Containerized environment with Docker Compose.
⚙️ **Automation** - comprehensive `Makefile` for DevOps tasks.

## 🏗 Architecture

The project follows a ** Clean Architecture** pattern ensuring separation of concerns and maintainability:

````
src/
├── main/
│   ├── java/com/progresssoft/warehouse/
│   │   ├── controllers/      # REST Controllers
│   │   ├── dto/              # Data Transfer Objects
│   │   ├── exception/        # Global Exception Handling
│   │   ├── mapper/           # MapStruct Mappers
│   │   ├── model/            # JPA Entities
│   │   ├── repository/       # Data Access Layer
│   │   ├── service/          # Business Logic
│   │   ├── utils/            # CsvParser & Helpers
│   │   └── validation/       # Custom Validators
│   └── resources/
│       └── application.yml   # Configuration
└── test/                     # 100% Covered Unit Tests
````
